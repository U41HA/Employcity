# Корзина кофейни · Ionic + Vue 3 + Capacitor

Экран корзины для мобильного приложения кофейни (iOS / Android / web): меню, добавление товаров, изменение количества, удаление свайпом, промокоды и итоговая сумма. Корзина сохраняется на устройстве и переживает перезапуск, а при открытии сверяется с актуальным каталогом: если цена или наличие изменились, пользователь видит уведомление.

## Запуск

```bash
npm install
npm run dev            # dev-сервер Vite
npm run check          # типы + линтер + форматирование + тесты (то же, что в CI)
npm run build:preview  # демо одним HTML-файлом
```

## Мобильное приложение (Capacitor)

Веб-сборка (`dist`) упаковывается Capacitor в нативный проект. Папка `android/` уже в репозитории.

```bash
npm run cap:sync      # собрать веб-часть и скопировать её в нативные проекты
npm run android       # открыть проект в Android Studio (Run ▶ — запуск на эмуляторе или телефоне)
npm run android:run   # собрать и запустить на подключённом устройстве из терминала
```

Нужны Android Studio и JDK 21. Для iOS: `npx cap add ios`, затем Xcode на macOS.
Хранилище корзины на устройстве — нативный плагин `@capacitor/preferences` (SharedPreferences на Android, UserDefaults на iOS).

## Архитектура

```
src/
  modules/cart/
    domain/       чистая логика без Vue: деньги в копейках, остатки, промокод, сверка с каталогом
    application/  Pinia setup-store: офлайн-сохранение через Capacitor Preferences, безопасная гидрация
    ui/           CartPage (Ionic), доступный QuantityStepper
  shared/ui/      иконки и «рисованная» галочка дизайн-системы
  app/            оболочка: роутер с табами, тема, экран меню
  demo/           демо-каталог и промокоды (в реальном приложении — API)
```

## Решения

- **Деньги — целые копейки** (branded-тип `Kopecks`): никаких `0.1 + 0.2`, округление один раз на границе.
- **Домен не знает про фреймворк**: правила корзины — чистые функции, возвращающие `Result`, а не бросающие исключения. Их можно переиспользовать в web-версии и тестировать без моков.
- **Недоверие к хранилищу**: данные из `Preferences` валидируются по форме; повреждённые или недоступные (приватный режим) не ломают запуск.
- **Гидрация до первого рендера**: корзина восстанавливается в `main.ts` до монтирования, поэтому действия в меню не перезаписывают сохранённое состояние.
- **Сверка с каталогом** при каждом входе на экран: устаревшие цены обновляются, недоступные позиции удаляются, количество ограничивается остатком.
- **Доступность**: подписи для скринридеров у плиток и степпера, `role="group"`, `aria-live`, видимый фокус, `prefers-reduced-motion`, контраст текста по WCAG AA.
- **Единый стиль кода**: только стрелочные функции и `<script setup lang="ts">` — закреплено правилами ESLint, форматирование через Prettier, всё проверяется в CI.

## Стек

Vue 3.5 (Composition API, `<script setup>`), TypeScript (strict), Pinia, Ionic Vue 9, Capacitor Preferences, Capacitor 8, Vite, Vitest + Vue Test Utils, ESLint (typescript-eslint, eslint-plugin-vue), Prettier, GitHub Actions.
